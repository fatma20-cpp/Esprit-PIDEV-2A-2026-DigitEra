# DigitEra – Digital Collaboration Platform

## Overview

This project was developed as part of the PIDEV – 3rd Year Engineering Program at **Esprit School of Engineering** (Academic Year 2025–2026).

**Digit Era** is a digital platform that connects brands, creators, influencers, and designers in order to manage collaborations efficiently.

The platform centralizes all operations such as user management, orders, finance, and customer service into one unified system.

---

## Features

- User authentication and subscription management  
- Brand validation and filtering  
- Creator profile and service management  
- Human resources management  
- Financial management (packs, invoices, payments)  
- Order and service request management  
- Customer service (reviews and complaints)

The system is based on a modular architecture including:
